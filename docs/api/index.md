# Public API index

- `nssl.io`: dataset validation, `chronological_index`, MNE adapter.
- `nssl.preprocessing`: `ChannelStandardizer`.
- `nssl.embedding`: `PCAEmbedding`, `FactorAnalysisEmbedding`.
- `nssl.trajectories`: velocity and centroid utilities.
- `nssl.references`: `ConditionReference`, leave-one-out references.
- `nssl.perturb`: isotropic, axis, empirical-residual, state-swap operators.
- `nssl.dynamics`: exact continuous linear and trained ridge transition models.
- `nssl.metrics`: reference distance and recovery-related descriptive measures.
- `nssl.nulls`: temporal, spectral and exchangeability-dependent null tools.
- `nssl.statistics`: confidence intervals and empirical permutation probabilities.
- `nssl.simulation`: known-answer synthetic systems and regression-to-mean trap.
- `nssl.validation`: known-answer checks.
- `nssl.demo`: seeded synthetic figures and numerical metadata.

See the package docstrings and tests for parameters and boundaries. API stability across future releases is not guaranteed.

# Scientific assumptions and interpretation contract

## Three distinct questions

- **Observational:** are recorded states nearer to an independently estimated reference at later times?
- **Known-system intervention:** how does a mathematically specified state evolve following an imposed displacement?
- **Fitted-model counterfactual:** how does a changed state evolve under a validated approximate predictive model?

A one-time displacement does not determine a future trajectory. A modeled future is not an observed biological response. Comparing the original future against a single changed state without propagation is not a legitimate perturbed rollout.

No attractor proof from reference distance alone; no brain stimulation or diagnosis; no cross-person generalization without independent evaluation. State the time/sensor units, split, embedding, reference, perturbation, evolution model, thresholds, null validity and selection rules.
